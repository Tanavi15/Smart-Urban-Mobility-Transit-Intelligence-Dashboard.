# Smart Urban Mobility & Transit Intelligence Dashboard

Infosys Springboard Virtual Internship 7.0 Project

## Project Overview
Smart Urban Mobility & Transit Intelligence Dashboard is a Power BI-based business intelligence solution developed to analyze urban transportation data and generate actionable insights for mobility planning, demand forecasting, route performance evaluation, congestion analysis, transit reliability monitoring, and executive decision-making.

## Technologies Used
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling (Star Schema)
- Data Visualization

## Key Features
- Demand & Transit Performance Analysis
- Route Efficiency Monitoring
- Mobility Demand Intelligence
- Demand Forecasting
- Anomaly Detection
- Executive Intelligence Dashboard
- Mobility Access Analysis
- Transit Reliability Tracking
